# SMC17

Sean Collins. Northwestern / Medill-adjacent builder. Tools for making
infrastructure and evidence *legible* — the same job Knight Lab does for
stories, applied to cables, markets, and proofs.

Most of the workbench stays private. A large private corpus is not a
portfolio. [TimelineJS](https://timeline.knightlab.com) won because it was
one tool a journalist could use, not four hundred repositories.

## Public

| Tool | One sentence |
|---|---|
| [logic-zig](https://github.com/SMC17/logic-zig) | An executable museum of logic: one system, one evidence file, Zig. |
| [finance-segway](https://github.com/SMC17/finance-segway) | The story behind the numbers: hashed historical cases, not a forecast. |
| [MarketDataSimulator](https://github.com/SMC17/MarketDataSimulator) | A teaching exchange: snapshot and incremental market data. |
| [lean-action](https://github.com/SMC17/lean-action) | A contribution fork of Lean CI — not a product. |

## Studio (private until a stranger can run them)

Maps of submarine cables. Hugging Face tokenizers and safetensors in Zig.
An EVM that diffs against the spec. An editor kernel. An SBOM checker.

Those become public one at a time, after a clean clone builds and a
five-minute README exists.

## How to read claims

- Status words: sketch / scaffold / compiled / unit-tested / integration-tested / audited / benchmarked.
- Speedups without commit, hardware class, workload, and script are not claims.
- Repo count is not a credential.
